# Noise

Social audio and media sharing platform with live voice chatrooms, stories, feeds, reels, and messaging built with Kotlin and Jetpack Compose for Android.

## Features

- **Live Voice Chatrooms**: Join audio lounges with speaker stages, 6 interactive speaker seats, live audience participation, raise-hand requests, and integrated real-time stage chatrooms.
- **Stories & Media**: View and share disappearing ephemeral stories with rich media viewer.
- **Content Feed & Reels**: Explore community posts, video reels, rich media, comments, and like reactions.
- **Direct Messaging & Community Lounges**: Chat with friends and members in real time.
- **Profiles & Coin Store**: User customization, profile settings, and virtual coin balance.

## Tech Stack

- **Platform**: Android (minSdk 24, targetSdk 36)
- **Language**: Kotlin 2.2.10
- **UI Framework**: Jetpack Compose with Material 3 Design
- **Architecture**: MVVM with Kotlin Coroutines and StateFlow
- **Image Loading**: Coil Compose
- **Backend / Cloud**: Firebase Firestore & Firebase Auth

## Running Locally

1. Open this repository in [Android Studio](https://developer.android.com/studio).
2. Allow Gradle sync to complete.
3. Run the app on an Android device or emulator running Android 7.0 (API 24) or higher.
